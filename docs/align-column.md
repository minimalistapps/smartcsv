# Align columns :material-professional-hexagon:{ .pro title="Available for PRO version only" }

By default, SmartCSV aligns number columns to the right and text columns to the left. To change it for a column:

- Tap the column's header to select it.
- Tap **Layout** in the bottom bar to open the Layout panel.
- Under **Align**, pick **Left**, **Center** or **Right**. The change applies as soon as you tap it &mdash; there's nothing to confirm.

Selecting a band of several columns with different alignments shows no thumb selected (mixed), and setting one applies it to the whole band.
